# 📊 Бот для сравнения цен на запчасти
Телеграм-бот для автоматического поиска и сравнения цен на промышленные запчасти. Отправляете артикулы — получаете сравнение от разных поставщиков, AI-анализ и Excel-отчёт.

## Что делает

Ищет цены по каталожным номерам у разных поставщиков


Сравнивает предложения и даёт рекомендации через Mistral AI


Сохраняет историю запросов в MySQL


Генерирует Excel-отчёты с цветовым форматированием


Показывает динамику цен за последний месяц

## Установка
```
Установите зависимости
pip install -r requirements.txt

Создайте файл .env с настройками
TELEGRAM_BOT_TOKEN=ваш_токен
MISTRAL_API_KEY=ваш_ключ
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=пароль
MYSQL_DATABASE=parts_db

Запустите бота
python main.py


Использование

Отправьте боту артикулы через запятую:

BP-12345-67890, MC-54321-09876


Можно указать конкретных поставщиков:

BP-12345-67890 !industrialsupply !machineparts

Команды:

/start — инструкция по использованию
/help — справка
/history BP-12345-67890 — история цен за 30 дней
```
